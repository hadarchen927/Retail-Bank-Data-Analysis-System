# 基于Spring Boot的零售银行数据分析系统

## 🎓 项目概述

本项目是一个毕业设计作品，旨在设计并实现一个基于主流微服务框架 Spring Boot 的数据分析系统，为零售银行业务提供一个高效、可靠的数据处理与分析平台。

### 项目背景

随着互联网技术和大数据技术的发展，传统零售银行业务积累了海量的客户信息、交易记录和行为数据。本系统通过数据分析挖掘这些数据背后隐藏的商业价值，以支持科学决策、提升服务质量、进行精准营销和风险控制。

## ✨ 核心功能

- **📊 数据统一管理**：整合多源银行业务数据，建立统一的数据管理平台
- **📈 多维度分析**：提供客户行为分析、交易趋势分析、风险评估等多维度数据分析
- **🎯 精准营销支持**：基于数据挖掘实现客户画像和精准营销策略
- **⚠️ 风险控制**：实时监控异常交易，提供风险预警机制
- **📱 可视化展示**：交互式数据可视化界面，直观展示分析结果
- **🔐 安全保障**：完善的权限管理和数据安全机制

## 🛠️ 技术栈

### 后端技术
- **核心框架**：Spring Boot 2.x
- **数据访问**：Spring Data JPA / MyBatis
- **数据库**：MySQL 8.0
- **缓存**：Redis
- **API文档**：Swagger / Knife4j
- **安全框架**：Spring Security + JWT

### 前端技术
- **框架**：Vue.js 3.x
- **UI组件库**：Element Plus / Ant Design Vue
- **数据可视化**：ECharts / D3.js
- **状态管理**：Vuex / Pinia
- **HTTP客户端**：Axios

### 开发工具
- **构建工具**：Maven / Gradle
- **版本控制**：Git
- **开发IDE**：IntelliJ IDEA / VS Code

## 🚀 快速开始

### 环境要求

- JDK 1.8+
- Node.js 14+
- MySQL 8.0+
- Redis 5.0+
- Maven 3.6+

### 后端启动

```bash
# 进入后端目录
cd backend

# 配置数据库连接
# 编辑 src/main/resources/application.yml

# 安装依赖并启动
mvn clean install
mvn spring-boot:run
```

### 前端启动

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 访问系统

- 前端地址：http://localhost:8080
- 后端API：http://localhost:8088
- API文档：http://localhost:8088/swagger-ui.html
